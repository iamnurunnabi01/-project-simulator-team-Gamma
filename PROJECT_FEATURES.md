# Implemented Features

## Student Age
The system stores the age of every student.

## Student CGPA
The system stores the CGPA of every student.

## Student Department
The system stores the department of every student.

## Student Email
The system stores the email address of every student.

## Student Phone Number
The system stores student phone numbers with support for up to 25 characters.

## Student Address
The system stores student addresses with support for up to 200 characters.

## Student Gender
The system stores the gender of every student.

## Student Semester
The system stores the semester of every student.

## Student Credit Hours
The system stores the credit hours of every student.

## Student Status
The system stores the status of every student.

## Improved Student Name Capacity
Student names support up to 100 characters.

## Student ID Field
The Student structure uses `studentId` as the student identification field.

## Student Name Field
The Student structure uses `studentName` as the field for student names.

## Current Student Structure
The Student structure currently contains:
- `studentId`
- `studentName`
- `age`
- `cgpa`
- `department`
- `email`
- `phone`
- `address`
- `gender`
- `semester`
- `creditHours`
- `status`
