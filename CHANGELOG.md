# Changelog

## Version 1.3
- Increased student name capacity from 50 to 100 characters.
- Increased student address capacity from 100 to 200 characters.
- Increased student phone number capacity from 20 to 25 characters.
- Renamed the Student ID field from `id` to `studentId`.
- Renamed the Student name field from `name` to `studentName`.

- Added email field to Student structure.
- Added phone number field to Student structure.
- Added address field to Student structure.
